# VectorScript

兵藤善紀建築設計事務所のVectorworks用プラグインです。

[LICENSE](LICENSE)に記載した適用範囲と各ライセンスの条件に従っていただければ、個人利用・業務利用ともにご使用いただけます。スクリプト等とSDK追加関数では条件が異なりますので、ご利用前にご確認ください。

## プラグイン目次

| プラグイン | 概要 |
| --- | --- |
| [ha_ij_direction](plugins/ha_ij_direction/) | 基準線に沿うi方向・直交するj方向への図形の移動・複製と、矩形で囲んだ頂点の移動を行うツールセットです。距離計測、線の傾き取得、距離・角度履歴を備えています。Windows x64 / Vectorworks 2026向け。 |

ダウンロード、導入方法、使い方は、各プラグインディレクトリのREADMEをご覧ください。プラグインは今後追加していく予定です。
